## Engineering case study — Caliber

Caliber was a creator biolink platform that combined profile customization, social integrations and payment workflows. The service and its database are no longer running. This case study describes previous development experience, not an active deployment.

**Architecture used:** Next.js, TypeScript, React, PostgreSQL, Supabase, Tailwind CSS and Cloudflare.

| Challenge | Engineering approach |
|:--|:--|
| Media delivery and bandwidth costs | Designed a read-through caching approach using object storage and a CDN |
| Payment reliability | Worked with webhook verification and idempotent entitlement grants |
| Data access | Used database migrations and row-level security policies |
| External integrations | Worked with OAuth and third-party APIs |
| Application security | Explored server-side request forgery prevention and input validation |

The project reinforced the importance of monitoring resource consumption, designing for failure and evaluating infrastructure trade-offs before deployment.
