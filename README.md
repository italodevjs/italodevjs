# Italo

Software developer based in Brazil. Interested in application security, deterministic systems and tools that make their assumptions visible.

This portfolio follows four concrete problems: developing a photograph, reasoning about time, inspecting geometry and understanding certificate lifecycles. Each project runs without an account or paid backend.

## Selected work

### Working Print

A photographic workbench with real pixel processing, before/after comparison and portable adjustment recipes. A separate Python renderer implements the same sRGB equations, with cross-language parity tests.

[Open the workbench](https://italodevjs.github.io/working-print/) · [Source](https://github.com/italodevjs/working-print) · [Algorithms](https://github.com/italodevjs/working-print/blob/main/docs/architecture.md) · [Study guide](https://github.com/italodevjs/working-print/blob/main/docs/study-guide.md)

### Early / Late

A playable rhythm timing laboratory with original synthesized audio, an editable chart and recorded replay. Its judgment engine separates song time from browser frames and handles chords, holds and interrupted runs explicitly.

[Play a study](https://italodevjs.github.io/early-late/) · [Source](https://github.com/italodevjs/early-late) · [Architecture](https://github.com/italodevjs/early-late/blob/main/docs/ARCHITECTURE.md) · [Study guide](https://github.com/italodevjs/early-late/blob/main/docs/STUDY.md)

### Section Plane

A local STL/OBJ inspection tool with topology diagnostics, actual section intersections and two-point surface measurements. It withholds volume when its consistency checks fail and documents what those checks cannot prove.

[Inspect a mesh](https://italodevjs.github.io/section-plane/) · [Source](https://github.com/italodevjs/section-plane) · [Geometry model](https://github.com/italodevjs/section-plane/blob/main/docs/ARCHITECTURE.md) · [Study guide](https://github.com/italodevjs/section-plane/blob/main/docs/STUDY_GUIDE.md)

### Not After

A public-certificate workbench with DER fingerprint deduplication, reproducible UTC evaluation and a sweep over declared renewal windows. Metadata inspection is kept separate from TLS trust validation.

[Inspect certificates](https://italodevjs.github.io/not-after/) · [Source](https://github.com/italodevjs/not-after) · [Inspection model](https://github.com/italodevjs/not-after/blob/main/docs/ARCHITECTURE.md) · [Study guide](https://github.com/italodevjs/not-after/blob/main/docs/STUDY.md)
